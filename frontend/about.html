ℹ️ About AirWatch System

Full System Specifications, Technical Architecture, Security Practices, and AQI Standard Documentation.

AIRWATCH

Web-Based Air Quality Data Collection, Monitoring and Analysis System

AirWatch is a complete, production-grade full-stack environmental monitoring platform built to capture, analyze, and visualize daily atmospheric pollution indicators across multiple monitoring stations. The system provides real-time aggregate statistics, location comparison analytics, printable environmental summary reports, and full CRUD data management.

🏗️ Core System Architecture

AirWatch enforces strict separation of concerns. The browser frontend never communicates directly with the database; all data operations are brokered through RESTful PHP backend endpoints. 

                      AIRWATCH APPLICATION
                               │
            ┌──────────────────┴──────────────────┐
            ↓                                     ↓
     FRONTEND LAYER                         DATABASE LAYER
    (HTML5 / CSS3 / Vanilla JS)             (MySQL 8.0+ / MariaDB)
            │                                     ↑
            │ JavaScript fetch() API               │ PDO Prepared
            ↓                                     │ Statements
     PHP REST API LAYER ──────────────────────────┘
   (create.php, read.php, statistics.php, etc.)

💻 Frontend Stack

  • HTML5: Semantic layout structure and responsive forms.
  • CSS3: Light Environmental theme custom styling and flexbox/grid.
  • Vanilla JavaScript (ES6+): Asynchronous API calls, dynamic DOM manipulation.
  • Chart.js: Interactive canvas data visualizations.

⚙️ Backend Stack

  • PHP 8+: Object-oriented RESTful API endpoints.
  • PDO (PHP Data Objects): Database abstraction layer.
  • Prepared Statements: Parametric query execution preventing SQL injection.
  • JSON Engine: Standardized JSON API responses with HTTP status codes.

🗄️ Database & Environment

  • MySQL / MariaDB: Relational storage engine (`airwatch`).
  • Indexing: Optimized indexes on `location`, `record_date`, `aqi`, `pollution_source`.
  • Environment Support: Compatible with XAMPP, WAMP, and Linux Apache stacks.

📏 Documented Air Quality Index (AQI) Standard

AirWatch strictly adheres to the US EPA Air Quality Index (AQI) Standard for calculating health categories and rendering badge indicators across all pages, APIs, and printable reports.

AQI Range Status Category Color Code Health Advisory & Meaning
0 – 50 ● Good #10b981 (Green) Air quality is satisfactory, and air pollution poses little or no risk.
51 – 100 ● Moderate #d97706 (Yellow) Air quality is acceptable; sensitive individuals may experience minor irritation.
101 – 150 ● Unhealthy for Sensitive Groups #ea580c (Orange) Members of sensitive groups may experience health effects; general public less affected.
151 – 200 ● Unhealthy #dc2626 (Red) Some members of the general public may experience health effects.
201 – 300 ● Very Unhealthy #7c3aed (Purple) Health alert: The risk of health effects is increased for everyone.
301+ ● Hazardous #881337 (Maroon) Health warning of emergency conditions: everyone is more likely to be affected.

🔒 Real-World Security Practices

  • PDO Prepared Statements: All user input is bound parametrically to eliminate SQL injection vulnerabilities.
  • Server-Side Validation: PHP re-verifies mandatory fields, numerical bounds, date formats, and humidity ranges (0-100%).
  • XSS Prevention: Special characters are sanitized via htmlspecialchars() before output.
  • Clean Error Handling: Internal stack traces and database credentials are never exposed in JSON responses.

🔑 Authentication-Ready Architecture

The system architecture is structured to support future Role-Based Access Control (RBAC). Planned expansion tables include:

users (id, username, password_hash, role_id)
roles (id, role_name: 'Admin', 'Collector', 'Viewer')
